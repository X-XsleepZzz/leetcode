108. Convert Sorted Array to Binary Search Tree
問題: https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/description/

Given an integer array nums where the elements are sorted in ascending order, convert it to a height-balanced binary search tree.

 

Example 1:


Input: nums = [-10,-3,0,5,9]
Output: [0,-3,9,-10,null,5]
Explanation: [0,-10,5,null,-3,null,9] is also accepted:

Example 2:


Input: nums = [1,3]
Output: [3,1]
Explanation: [1,null,3] and [3,1] are both height-balanced BSTs.
 

Constraints:

1 <= nums.length <= 104
-104 <= nums[i] <= 104
nums is sorted in a strictly increasing order.

```py
class Solution:
    def sortedArrayToBST(self, nums: list[int]) -> TreeNode | None:
        def index_range_to_bst(left: int, right: int):
            if left > right:
                return None
            
            middle = (left + right) // 2
            node = TreeNode(nums[middle])
            node.left = index_range_to_bst(left, middle - 1)
            node.right = index_range_to_bst(middle + 1, right)
            return node
        return index_range_to_bst(0, len(nums) - 1)
```
binary search的な再帰
時間計算量は全て要素を見ていくので、要素数をnとしたらO(n)でn < 10^4 < 10^7 ≒ 1sなので0.5秒にもみたないくらい。
空間計算量はメモリ上にどれくらい積まれるかで決まるので、ここではツリーの深さを見ていく。
ツリーの深さはリストの要素数を何度も半分にしていく処理があるので、O(logn)
